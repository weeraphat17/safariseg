    ผลการเทรน: Rect vs Polygon

    ใช้ภาพชุดเดียวกันจาก COCO 2017 เทรน 2 แบบ ประเมินบนชุด test ที่โมเดลไม่เคยเห็น

    จำนวน Object ต่อ Label ทุก label มากกว่า 100 ตามเกณฑ์

    LabelRect mAP50Rect mAP50-95Polygon Box mAP50Polygon Mask mAP50Polygon Mask mAP50-95

    วิธีทำงาน

    1. Letterbox ย่อภาพให้ด้านยาวเป็น 640 คงสัดส่วน เติมขอบสีเทา แปลงเป็น tensor 1×3×640×640 ค่า 0–1
    2. ONNX Runtime Web รันโมเดล YOLO26n-seg ที่ export จาก best.pt ด้วย WebAssembly ในเบราว์เซอร์
    3. Decode output0 ให้กรอบ ความมั่นใจ class และสัมประสิทธิ์ mask 32 ค่า output1 คือ prototype mask 32×160×160
    4. Mask คูณสัมประสิทธิ์กับ prototype ผ่าน sigmoid ตัดเฉพาะในกรอบ threshold 0.5
    5. Polygon หาเส้นขอบของ mask แล้วลดจำนวนจุดด้วย Douglas–Peucker วาดเป็น polygon บนภาพจริง
